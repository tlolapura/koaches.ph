# Instagram app screenshots

Drop mobile screenshots here as PNG. Keep the filenames below.

Posts prefer `.png` and fall back to the `.svg` placeholder until you add a real shot.

| File | Capture this screen |
|------|---------------------|
| `dashboard.png` | Coach home / dashboard |
| `students.png` | Students roster |
| `session.png` | Session detail |
| `programs.png` | Programs list or preset picker |
| `progress-card.png` | Progress card (or share message) |
| `join-qr.png` | Student join QR |
| `billing.png` | Earnings / billing |
| `profile.png` | Public coach profile (mobile) |
| `schedule.png` | Schedule / calendar |
| `skill-rating.png` | Skill rating after a session |
| `clinic.png` | Clinic detail or enrollments |

Tips:
- Capture on a phone or responsive mobile width (~390px)
- Crop UI only (no status bar clutter if you can)
- Light mode, real sample data looks best
